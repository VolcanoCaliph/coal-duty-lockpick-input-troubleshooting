## 🎯 What This Does

This project documents how to recognize and troubleshoot **lockpick input troubleshooting** in **Coal Duty**. It focuses on **Lockpick interaction, co-op desynchronization and control response** with targeted checks, patch awareness, and reproducible testing so players can narrow down the actual cause instead of guessing.

## ✨ Features

- Tests lockpick interactions after the multiplayer lockpick patch.
- Compares the same lock interaction between the lobby host and a connected client.
- Checks keybind response and recreates the affected co-op session to isolate desync.

## 🔎 Symptoms Covered

- The lockpick mini-game does not react to expected input.
- Lockpick behavior differs for the host and clients.
- An interaction becomes stuck in a multiplayer session.

## 🛠️ Troubleshooting — Step by Step

1. **Install updates.** Multiplayer lockpick behavior was addressed in an early patch; test the latest build before using older advice.
2. **Check the input binding.** Confirm your action or interaction key works in normal gameplay.
3. **Compare host versus guest.** Try the same lock with the host, then another connected player.
4. **Restart the affected session.** If only one lobby is affected, create a fresh session and retest with two players.
5. **Report consistent repro steps.** Note game build, number of players, who was host and the exact input that stopped working.

## ❓ FAQ

**Does this project document an official game fix?**  
No. This is an independent community guide. Where an official patch addressed an issue, that context is noted above.

**What if I still see the issue after updating?**  
Record the exact game build, hardware and reproduction steps, then compare your result against each check in order.

**What if I only encounter the issue in multiplayer?**  
Test in a fresh session with the smallest possible party and record which player hosts.
